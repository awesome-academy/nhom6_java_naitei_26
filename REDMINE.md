## Quy ước quản lý task trên Redmine

- Mọi thành viên đăng ký tài khoản Redmine trên site trước khi bắt đầu dự án, đặt tên account theo đúng quy định của khóa học.
- Toàn bộ công việc phải được tạo thành ticket trên Redmine, không làm việc ngoài ticket.
- Mỗi ticket estimate tối đa 8 giờ. Task lớn hơn 8 giờ phải chia nhỏ thành nhiều ticket.
- Ticket cần điền đủ: Subject rõ ràng, Assignee, Estimated time, Start date, Due date.
- Cập nhật % Done và Spent time hàng ngày.
- Luồng trạng thái ticket: New - In Progress - Resolved - Closed.

## Quy ước liên kết Pull Request với Redmine

- Đặt tên nhánh theo mã ticket, ví dụ: feature/1234-create-user-model.
- Tiêu đề Pull Request bắt đầu bằng mã ticket, ví dụ: #1234 Create user model.
- Phần mô tả Pull Request phải dán link ticket Redmine tương ứng.
- Chỉ merge Pull Request sau khi ticket đã được review và approve.
